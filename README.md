#  ESI Journey

A simple archive of labs (TPs) and projects from my time at the **École Nationale Supérieure en Informatique (ESI)**.

##  What's inside?

This repository contains only practical coursework:

- 🧪 **Labs (TPs):** Lab exercises, weekly assignments, and practical problem sets.
- 💻 **Projects:** Semester projects and group assignments built for various modules.

##  Purpose

- **Backup & Storage:** Keeping all my practical coursework organized in one place.
- **Peer Resource:** Giving fellow ESI students a reference point if they're stuck on a similar lab or looking for inspiration on class projects.

##  Questions or Feedback?

If you're an ESI student and have questions about any of the labs or projects, feel free to open an issue. If you find these references helpful, feel free to drop a ⭐ on the repo!
